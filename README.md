Proyecto - Mi portafolio -
Portafolio profesional, creado a partir de HTML y CSS. 

1. Creación:
Se uso figma para diseñar un pequeño boceto de la página web y se utilizo una paleta de colores.

2. Creación de los archivos:
Se crearon los archivos index.html y style.css para la estructura de la pagina y el estilo del mismo. Se utilizaron etiquetas como header, di y footer, y clases para etiquetarlas.

3. Carpetas adicionales:
Se crearon carpetas como img e icons para las imagenes y los iconos utilizados en la página web.

4. Estructura:
La pagina web cuenta con la siguiente estructura: Un header (nav y home), una seccion sobre mi (Con datos personales y educación), una sección de proyectos, una sección de mis habilidades, una sección de contacto (Formulario y redes sociales) y finalemnte un footer al final.

5. Estilos:
Finalmente, se agregaron diveros estilos para obtener una pagina web visualmente atractiva y facil de interpretar.

6. LINK: https://lossesa.github.io/mi-portafolio/
